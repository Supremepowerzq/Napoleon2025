## Slide 1 — 本周目标：从单路径回放升级为五叶段全流程自主巡检

## Slide 2 — Layer 1：五条离散轨迹的公共点拼接与完整闭环

### 固定巡检顺序

```text
TR
 → LUB 左上
 → LLB 左下
 → RUL 右上
 → RML 右中
 → RLL 右下
 → TR 原点
```

| 模块 | 实现方法 | 本次结果 |
|---|---|---|
| **轨迹选择** | UI 中分别选择 LUB/LLB/RUL/RML/RLL 五条 JSON；顺序固定、文件可更换，适应现场重新录制 | 已完成可视化设定和规划提示 |
| **公共点搜索** | 在 `(M0,M1,M2)` 三轴角度空间中寻找相邻轨迹重复或近似重复点 | 找到 4 组相邻公共点 |
| **轨迹切换** | 当前叶段终点沿原轨迹回退到公共点，必要时插入短连接段，再沿下一条轨迹前进 | 无需每次退回 TR |
| **最终返航** | 完成 RLL 后沿轨迹反向返回 TR 原点 | 实机成功返回出发点 |
| **安全约束** | 启动前验证五条轨迹、公共点和 TR 起点；选择变化后要求重新规划 | 原有单路径功能保持不变 |

### 当前轨迹分段

```text
forward       前往目标叶段
backtrack     回退到相邻轨迹公共点
bridge        公共点之间的短连接
return_origin 完成巡检后返回 TR
```

### 本次规划与实机结果

```text
离线拼接总步数：7954
相邻公共点：4 组
巡检顺序：LUB → LLB → RUL → RML → RLL
终点：TR 原点
```

**实机结论：**

- 第一版纯 Layer 1 已经能够顺利完成五叶段全流程自主巡检。
- 相邻叶段之间能够在公共点回退和切换。
- 整个流程能够连续执行，完成后回到出发原点。
- 证明“执行前完成整条轨迹规划”的方案可行，可作为 Layer 2/3 的稳定主路径。

## Slide 3 — Layer 2 与阻塞物图控实验：主轨迹稳定，视觉只做可信修正

### Layer 2 设计原则

```text
最终目标角度
  = Layer 1 当前基础轨迹目标
  + Layer 2 有限视觉偏置
```

Layer 2 不逐帧累积，不接管 M0 前进轴，只对 M1/M2 做有限修正。

| 门控条件 | 当前策略 |
|---|---|
| **巡检阶段** | 仅在 `forward` 前进段允许修正；回退、连接和返原点严格执行 Layer 1 |
| **岔口位置** | 中心距离 ≤0.12 时完整响应；0.12–0.35 逐渐减弱；≥0.35 完全关闭 |
| **稳定性** | 连续稳定 4 帧才允许介入；候选跳变 >0.12 时重新稳定 |
| **视觉时效** | 数据年龄 >0.25 s、检测丢失或异常时立即清零偏置 |
| **修正幅度** | M1 最大 ±2.0°，M2 最大 ±1.5°；EMA 系数 0.25 |
| **候选选择** | 使用几何中心距离画面中心最近的岔口候选，不再简单选择最大腔道 |

### 实机结果对比

| 实验 | 配置 | 结果 |
|---|---|---|
| **实验 A** | 纯 Layer 1 全流程 | 五叶段巡检和返回 TR 均顺利完成 |
| **实验 B** | Layer 1 + 保守式 Layer 2 | 保持整体路径稳定；岔口中心接近画面中心时可实时微调，自主介入效果优于单纯回放 |
| **实验 C** | 独立图控 Mode 2 阻塞物追踪 | 机器人接近阻塞物、目标面积达到画面约 1/3 以上时，能够较好地自主跟踪和对准 |

### 本次工程修复

- 修复图控左右方向重复反号问题。
- 删除错误的 `cv2.setWindowTitle()`，切换 1/2/3 时不再弹出灰色空窗。
- UI 最底端增加三个小按钮：

```text
1 岔口追踪
2 阻塞物追踪/清除
3 阻塞物优先混合追踪
```

- 键盘与 UI 共用线程安全的模式状态。

### 当前实验边界

- 当前结论属于功能性验证，尚未统计重复次数和显著性。
- 尚缺少中心线平均误差、最大偏差、碰撞次数和全流程耗时等定量指标。
- Mode 2 已验证“大目标近距离跟踪”，小目标捕获距离和成功率仍需测试。

## Slide 4 — 下一步：Layer 3 阻塞物优先清除与断点续航

### 目标

当全流程自主导航过程中出现阻塞物，且阻塞物面积超过可信阈值时：

```text
立即暂停自主导航
→ 优先追踪并清除阻塞物
→ 清除后返回导航断点
→ 从断点继续执行剩余巡检轨迹
```

### 计划状态机

```text
NAVIGATING
    │
    │ obstruction_detected
    │ AND area >= A_enter
    │ AND 连续确认 N_enter 帧
    ▼
SAVE_CHECKPOINT
    保存：全流程步骤、阶段、Layer 1 基础目标、M0/M1/M2 实际角度
    ▼
CLEARING
    暂停 SequencePlayer
    关闭 Layer 2
    切换 Mode 2
    M1/M2 对准阻塞物，M0 按深度安全靠近
    真空泵持续吸引
    │
    │ 连续 N_clear 帧未检测到阻塞物
    │ 或 area <= A_exit
    ▼
RETURNING
    按保存的三轴角度返回断点
    │
    │ 三轴误差均进入容差并稳定若干帧
    ▼
RESUME
    恢复 SequencePlayer 步骤索引
    重置 Layer 2 EMA/稳定帧
    继续 NAVIGATING
```

### 第一版建议参数

| 参数 | 初始建议 | 作用 |
|---|---:|---|
| `A_enter` | 0.30–0.33 | 结合本次“面积约 1/3 时追踪稳定”的实机观察，作为第一版触发范围 |
| `N_enter` | 4 帧 | 避免单帧误检中断导航 |
| `A_exit` | 低于 `A_enter`，建议 0.10–0.15 | 形成迟滞，防止清除/导航状态反复切换 |
| `N_clear` | 15 帧 | 连续未检测到目标后才判定清除完成 |
| 返回容差 | ≤5° | 三轴返回断点的到位判据 |
| 清除超时 | 待实机标定 | 超时后停止并请求人工接管，不能无限追踪 |

最终阈值应通过多次实机实验标定，不直接以单次观察固定。

### 关键实现原则

1. **导航优先级切换**：Layer 3 激活后冻结 Layer 1 步骤，不能边清除边推进路径。
2. **断点完整性**：不仅保存步骤索引，还保存阶段类型、基础目标和三轴实际角度。
3. **迟滞与连续帧**：进入和退出使用不同面积阈值，避免目标面积在临界值附近抖动。
4. **泵控制简化**：真空吸引泵全程开启，不新增电机开关；Layer 3 只负责对准和靠近。
5. **安全退出**：清除超时、视觉停更、深度无效或电机异常时立即停止，允许人工接管。
6. **恢复隔离**：回到断点后重置 Layer 2 平滑状态，避免清除阶段的视觉残差带入导航。
7. **第一版范围**：优先在全流程 `forward` 阶段启用 Layer 3，验证稳定后再评估回退段是否需要处理阻塞物。

### 验证计划

| 阶段 | 验证内容 | 通过标准 |
|---|---|---|
| **离线状态机** | 误检、连续检测、清除、返回和续航 | 状态顺序正确，轨迹步骤不丢失 |
| **静态阻塞物** | 不同面积、位置和深度 | 超阈值稳定触发，低于阈值不误触发 |
| **断点返回** | 不同叶段和不同阶段触发 | 三轴回到断点，误差≤5° |
| **完整闭环** | 五叶段巡检中随机放置阻塞物 | 清除后继续剩余轨迹并最终返回 TR |
| **对照实验** | Layer 1+2 与 Layer 1+2+3 | 比较完成率、阻塞清除率、耗时和碰撞次数 |
