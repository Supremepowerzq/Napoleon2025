## [下午] 专利插图全套绘制

**任务**：基于开题报告风格，绘制 13 张专利 / 软件著作权申请所需的系统架构、控制流程、网络结构图，并保存到 `G:\zq\Napoleon2025\新建文件夹\patent\proposal_images`。

**关键决策**：
- **技术栈**：继续沿用 PowerShell + .NET `System.Drawing` 方案，沿用 `helpers.ps1` 提供的 `Draw-TextC/TextL/Box/RBox/Ellipse/Diamond/Line/DashLine/Arrow/TwoArrow` 等函数。画布尺寸 1600x900 ~ 1700x1000 像素。
- **字符编码流程**：`Write` 工具只能写 UTF-8 (无 BOM)，而 PowerShell 5.1 解析 UTF-8 中文时会把多字节序列当 CP1252 解读为 `?`。最终采用三步走：
  1. 把 `draw_fig*.src.ps1` 用 `Write` 工具写成 UTF-8（人工可读源）
  2. 用 `Get-Content -Raw -Encoding UTF8` 读源码到 .NET 字符串（正确解码）
  3. 用 `[System.IO.File]::WriteAllText` + `New-Object System.Text.UnicodeEncoding($false,$true)` 写为 UTF-16 LE with BOM
  4. PowerShell 直接执行 UTF-16 LE 文件，中文正常解析
- **辅助文件**：创建 `C:\tmp\patent\utf16_gen.ps1` 接收 `src` 和 `out` 两个路径参数，执行上述转换。
- **staging 模式**：所有 PNG 先存到 `C:\tmp\patent\staging`（纯 ASCII 路径，避开 GDI+ 外部异常），再 `Copy-Item` 到目标中文路径 `proposal_images`。
- **helpers 修复**：补齐 `Draw-Diamond`（`PointF` 参数类型问题，PowerShell 5.1 不接受 `New-Object PointF ([float]x, [float]y)` 多参数构造，必须先 `[float]$xF` 再 `($xF, $yF)` 传入）和 `Draw-Arrow/TwoArrow`（`LineCap.Arrow` 不存在，改用 `LineCap.ArrowAnchor`）。
- **括号笔误修复**：图 3 多处 `FillRectangle/DrawRectangle` 末尾误打 `])`，用 `StrReplace` 修复。
