# BGR Color Picker - BGR调色工具

一个基于OpenCV的实时BGR颜色调色工具，支持中文显示和颜色保存功能。

## 功能特性

- **实时调色**: 通过滑块或键盘实时调整BGR颜色值
- **颜色预览**: 大尺寸预览窗口实时显示当前颜色
- **中文支持**: 解决OpenCV中文显示乱码问题
- **多种调整方式**:
  - 鼠标拖动滑块
  - 键盘快捷键 (B/G/R键增加，b/g/r键减少)
  - 空格键随机颜色
- **颜色保存**: 保存颜色配置到JSON文件
- **颜色复制**: 复制颜色值到剪贴板文件
- **历史记录**: 自动保存最近10个颜色历史

## 使用方法

### 运行脚本
```bash
cd 2026
python color_picker_bgr.py
```

### 操作说明

#### 界面说明
- **控制窗口**: 包含三个滑块(BGR)和当前数值显示
- **预览窗口**: 显示当前颜色和操作说明

#### 键盘快捷键
- `B/G/R`: 增加对应颜色分量 (步长5)
- `b/g/r`: 减少对应颜色分量 (步长5)
- `空格`: 生成随机颜色
- `S`: 保存当前颜色到文件
- `C`: 复制颜色值到剪贴板文件
- `ESC`: 退出程序

#### 鼠标操作
- 拖动滑块调整颜色值 (0-255范围)

## 输出格式

### 控制台显示
```
BGR Color Picker 启动
操作说明:
  - 拖动滑块调整颜色值
  - 按 B/G/R 键增加对应颜色
  - 按 b/g/r 键减少对应颜色
  - 按空格键生成随机颜色
  - 按 S 键保存当前颜色
```

### 保存文件格式 (JSON)
```json
{
  "current_color": {
    "bgr": [128, 64, 192],
    "hex": "#8040C0",
    "rgb": [192, 64, 128],
    "timestamp": "2024-01-22 14:30:00"
  },
  "history": [
    {
      "bgr": [128, 64, 192],
      "hex": "#8040C0",
      "rgb": [192, 64, 128],
      "timestamp": "2024-01-22 14:30:00"
    }
  ]
}
```

### 剪贴板文件 (clipboard_color.txt)
```
BGR: (128, 64, 192)
HEX: #8040C0
RGB: (192, 64, 128)
```

## 技术实现

- **GUI框架**: OpenCV
- **中文显示**: PIL + 系统字体
- **数据存储**: JSON格式
- **颜色空间**: BGR (OpenCV标准)

## 系统要求

- Python 3.x
- OpenCV (cv2)
- PIL (Pillow)
- NumPy

## 字体支持

程序会自动检测系统中的中文字体：
1. 黑体 (simhei.ttf)
2. 仿宋 (simfang.ttf)
3. 宋体 (simsun.ttc)
4. 微软雅黑 (msyh.ttc)

如果检测不到合适字体，将使用PIL默认字体。

## 文件说明

- `color_picker_bgr.py`: 主程序文件
- `color_saves_YYYYMMDD.json`: 每日颜色保存文件
- `clipboard_color.txt`: 剪贴板模拟文件

## 注意事项

1. 程序会在当前目录生成保存文件
2. 中文显示需要系统安装中文字体
3. 颜色历史记录最多保存10个
4. 剪贴板功能通过文件模拟，如需真复制功能可安装pyperclip库
