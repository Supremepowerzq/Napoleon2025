# 当前研究状态与 IEEE RA-L 论文定位

日期：2026-07-13

## 1. 论文主线

论文保留并串联四个阶段：

1. **专家数据采集与 BC+goal 模仿学习**：采集真实机器人专家操作数据，使用目标条件化 GRU 学习多路径导航策略；已有阶段性上机结果支持“BC+goal 可实现稳定、目标导向导航”，最终稿中补填统一协议下的成功率、端点误差和重复次数。
2. **Layer 1 — 专家轨迹参考**：保留同一路径多次演示的平均轨迹，并增加选定单条原始轨迹的时间保持回放，为后续层提供可复现、可审计的参考。
3. **Layer 2 — 岔口视觉辅助**：在可信岔口检测下，相对 Layer 1 参考施加有界、可泄漏回零的视觉偏置，提高装配扰动和局部偏差下的分支选择能力。
4. **Layer 3 — 黏液清除与断点续航**：检测并追踪黏液，完成居中/接近后由独立三号电机 M3 开启吸引装置；清除后返回“序列进度 + 实际电机角度”双重断点并继续原路径。

建议论文问题定义为：

> 如何把真实专家数据驱动的目标条件化模仿学习，与可审计的专家轨迹参考、有界岔口视觉辅助及可恢复的黏液清除任务结合，从而实现长程、分层且可中断恢复的机器人支气管镜自主导航？

这一写法既保留模仿学习作为重要工作组成，也能自然解释为什么在 BC 之后仍需要 Layer 1--3：BC 提供多目标学习能力，轨迹参考提供重复性与降级基线，视觉反馈处理局部偏差，状态机处理治疗任务插入和恢复。

## 2. 已完成内容

### 2.1 专家数据与 BC+goal

- 已建立专家演示采集、数据读取、模型训练和实时 `BCRunner` 推理链路。
- 旧版专家库共 87 条演示、30,730 帧，覆盖 7 条已录制路径；该数据集同时支撑 BC 训练和早期平均轨迹构建。
- 模型使用 20 维结构化观测、8 帧时序窗口、16 维目标嵌入、两层 GRU（hidden 256）以及动作/任务双头输出。
- 论文保留“BC+goal 已实现稳定导航”的阶段性结果，但投稿表格中的闭环成功率、端点误差、碰壁次数和试验次数必须按统一实验协议补填。
- BC 数据集与当前 `AutoNavdatasets` 的 11 条新轨迹属于两个数据版本，论文中必须分表说明，不能混写为同一个数据集。

### 2.2 硬件与控制基础

- 三个导航电机链路已集成：M0 推进/回撤，M1 左右弯曲，M2 上下弯曲。
- 已修复 A4 多圈位置命令负角度的 16 位溢出问题；另有 3/3 项电机协议测试通过。
- 主程序已有手动采集、路径选择、开始/暂停/停止、回原点，以及 Layer 2/3 显式开关。
- Layer 3 计划新增独立 M3 电机，负责吸引泵或吸引装置的开/关；电机型号、角度/速度、泵负压和流量等参数暂留空。

### 2.3 Layer 1

- **平均轨迹模式**：同路径演示转换为相对起点的累计角度，重采样到中位数长度后逐帧取平均；这是 2026-07-01 版本及其 92 项软件验证所对应的实现。
- **单条轨迹模式**：当前基本上机实验使用 `AutoNavdatasets` 中选定的单条 JSON，按原始时间戳生成目标序列，速度缩放不改变最终位移。
- 路径结束后保持最终目标并等待真实电机到位；TR 回原点保持为独立模式，不作为普通导航路径。
- 已记录 LMB 离线终点保持 `[-158, 0, -91] deg`；LLB 跨越 `-327.68 deg` 后的反向异常已通过 32 位有符号编码修复。
- 当前 11 条新轨迹覆盖 LMB、RMB、LUB、LLB、RUL、RML、RLL 七类目标；现场重新采集后立即用于导航的流程已跑通。

### 2.4 Layer 2/3 软件基础

- 感知端可输出黏液/阻塞物中心、面积、检测标志，以及岔口候选中心和面积。
- `JunctionGuide` 已有基础 P 修正和 EMA 平滑。
- `ObstructionHandler` 已有追踪、返回、继续导航的状态转换，以及序列步和电机角度双重断点。
- 历史逻辑测试覆盖修正符号、EMA 衰减、阻塞物状态转移、返回断点和主循环集成。

## 3. “92 项测试全部通过”的准确含义

2026-07-01 版本共有：

| 测试套件 | 内容 | 历史结果 | 性质 |
|---|---|---:|---|
| `test_autonav.py` | 数据统计、Layer 1 序列、Layer 2 岔口、Layer 3 状态机、控制器端到端逻辑 | 81/81 | 无硬件模块/逻辑检查 |
| `test_autonav_integration.py` | 启动、导航、注入阻塞、清除状态、返回/续航、岔口引导、停止的主循环模拟 | 11/11 | 无硬件集成冒烟检查 |
| 合计 | AutoNav 历史软件验证 | **92/92** | **不是 92 次实体导航实验** |

这项结果应保留在论文的“Software Verification”中，用于说明平均轨迹版三层软件在当时版本通过全部逻辑断言。由于后续数据目录和接口已经调整，投稿前需更新脚本并在冻结版本上重跑；新结果在表格中单独填写。电机有符号协议的 3/3 项测试应另列，不计入上述 92 项。

## 4. 尚需完成的定量工作

### 4.1 BC+goal 结果补齐

- 固定训练/验证/测试划分，报告各轴动作 MSE/MAE、任务分类准确率和推理时延。
- 在相同目标、起点和安全阈值下比较 BC 无目标、BC+goal 单头、BC+goal 双头和人工操作。
- 对“稳定导航”给出可复核定义：目标分支到达、无强制接管、允许碰壁数、最大时长，以及每个目标的重复次数。
- 报告各目标成功率和 Wilson 95% 置信区间；若没有 EM/光学跟踪，不写毫米级端点误差，只报告分支到达和电机端点误差。

### 4.2 Layer 1 平均轨迹与单条轨迹对照

- 在相同路径上比较平均轨迹和选定单条轨迹的成功率、完成时间、墙接触、人工接管、跟踪误差和端点重复性。
- 测试标准起点、起点角扰动、速度缩放和重新装配条件。
- 对平均轨迹绘制多演示、重采样、均值和标准差带；对单条轨迹绘制时间插值前后曲线和不变终点。

### 4.3 Layer 2 安全化与岔口辅助

当前每帧修正不能继续无界积分。建议使用：

```text
q_cmd(t) = clip(q_ref(t) + b(t), motor_limits)
b(t) = clip(lambda * b(t-1) + G(t) K e(t), -b_max, b_max)
```

其中 `G(t)` 综合面积、置信度、候选稳定性、图像误差和电机跟随误差。实现前还需完成：

- M1/M2 图像方向到电机方向标定；
- 中心死区、可信面积/置信区间和大偏差门控；
- 相对参考的总偏置上限与无目标时泄漏回零；
- 电机未跟上时冻结新修正；
- 结合未来参考转向选择计划岔口；
- 感知丢失、候选跳变和偏置饱和时降级到 Layer 1 或安全停止。

### 4.4 Layer 3 M3 吸引链路

建议状态机为：

```text
NAVIGATE
  -> CONFIRM_MUCUS
  -> APPROACH_AND_CENTER
  -> M3_SUCTION_ON
  -> VERIFY_CLEARANCE
  -> RETURN_TO_CHECKPOINT
  -> VERIFY_RETURN_AND_RESUME
```

M3 只在黏液目标持续确认、居中误差小于阈值、深度位于工作区间且视觉质量合格时开启。任何视野丢失、超时、急停或回程故障都应立即关闭 M3。清除成功不能只依赖“目标消失”，至少同时记录 M3 实际动作和黏液面积/质量持续下降；条件允许时增加清除前后质量测量。

待填写参数包括：M3 型号、驱动方式、开/关角度或行程、最大速度、泵负压/流量、最大连续吸引时间、重试次数、居中阈值、深度区间、清除确认帧数和返回误差阈值。

## 5. 建议的投稿证据结构

1. **学习证据**：87 条专家演示的数据分布、BC+goal 网络与消融、稳定导航的定量复现实验。
2. **参考证据**：平均轨迹和单条轨迹的形成过程、重复性和对装配扰动的局限。
3. **辅助证据**：Layer 2 相比纯 Layer 1 提高岔口选择/路线成功，同时残差始终受限。
4. **恢复证据**：M3 完成吸引，系统返回双重断点并继续完成原路线。
5. **软件证据**：历史 92/92 与最终冻结版本重跑结果分列，避免把软件断言误解为实体导航试验。

若 Layer 3 尚未接入 M3，初稿可以写清楚设计和待填参数，但正式投稿的摘要、结果和结论只能在完成真实吸引闭环后宣称“autonomous mucus clearance”。
